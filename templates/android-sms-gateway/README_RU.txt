MYENGINE SMS GATEWAY R21 — ANDROID

Готовая сборка MyEngine_SMS_Gateway_R21.apk требует Android 8.0 или новее
и устройство с SIM/SMS. Устанавливается только на телефон автора.
В комплекте сервера есть README_RU.txt с настройкой Render, регистрацией
игроков и входом владельца по паролю без SMS. Начни с него.

ПРИЛОЖЕНИЕ
Адрес: HTTPS-origin сервера, без /verify или /api.
Номер SIM: международный +кодстраныномер. Этот номер не получает SMS из шлюза.
Ключ телефона: из private-config/phone-token.txt, не пароль владельца.
Дневной лимит: 20 по умолчанию, до 100; сутки по UTC.
Сохрани, разреши SMS и уведомления, выбери SIM для SMS по умолчанию в Android,
нажми «Запустить отправку». Остановить можно здесь или в уведомлении.
После перезагрузки запуск вручную. Для долгой работы используй зарядку.
При ошибках смотри статус приложения; в игру неизвестный статус не даёт вход.

СБОРКА ИСХОДНИКОВ НА WINDOWS
Открой эту папку в Android Studio. Нужны Android SDK Platform 35,
Build Tools 35.0.0, JDK 17 или 21. Проект использует AGP 8.7.3 и Gradle 8.9.
Можно запустить build_windows.ps1 из PowerShell: он скачает официальный Gradle
8.9 с проверкой SHA-256, возьмёт SDK из ANDROID_HOME или стандартной папки
%LOCALAPPDATA%\Android\Sdk и выполнит :app:assembleDebug.
Пример с явными путями:
  powershell -ExecutionPolicy Bypass -File .\build_windows.ps1 -Sdk "C:\Users\User\AppData\Local\Android\Sdk" -Jdk "C:\Program Files\Android\Android Studio\jbr"
JDK 26 для этой версии Gradle не используй; выбери 17 или 21.
Выход: app/build/outputs/apk/debug/app-debug.apk.
Локальная сборка Android Studio по умолчанию получит другой ключ подписи.
Для замены уже установленной готовой сборки понадобится её ключ подписи
либо удаление старого приложения с предварительным сохранением настроек.
Не коммить ключи подписи, ключ телефона, local.properties и private-config.

АРХИТЕКТУРА
MainActivity — настройки, разрешения, явные запуск и остановка.
GatewayService — foreground specialUse, очередь каждые 5 секунд, SMS через SIM.
GatewayApi — HTTPS, авторизация ключом телефона, запрет редиректов.
Vault — Android Keystore AES-GCM для настроек и журнала.
JobJournal — запись попытки ДО SmsManager, дневной лимит, результаты для сервера.
SmsSentReceiver — результат передачи SMS оператору; сам доступ не выдаёт.
Сервер принимает код независимо от задержки отчёта устройства. Задание никогда
не выдается повторно автоматически; потерянная отправка требует нового запроса.

Сборка APK, DEX и подписи проверены. На физическом телефоне приложение
ещё не проверялось; настоящие SMS во время подготовки не отправлялись.
