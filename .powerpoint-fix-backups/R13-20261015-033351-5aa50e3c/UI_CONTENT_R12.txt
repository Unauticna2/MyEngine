MyEngine 2.5 — UI CONTENT R12

УСТАНОВКА
1. Закрой Editor, Hub и окно игры/Viewport.
2. Распакуй MyEngine2_UIContent_R12.zip в отдельную папку.
3. Запусти INSTALL_UI_CONTENT_R12.cmd и выбери папку движка:
   F:\Users\User\Desktop\MyEngine
4. Запусти MyEngine2.exe, открой проект через Hub.
5. Assets / extensions → PowerPoint / 2D interface.
   В заголовке должно быть UI TOOLS R12. В окне есть полоса прокрутки.
6. Для уже импортированного UI нажми «Обновить текущий UI из PowerPoint».
   Презентация должна быть открыта. Это добавит данные текстовых полей и видео.

Пересборка EXE не нужна. MyEngineUI.dll и MyEngineVideo.dll включены.
Обновление содержит R11 (запуск Hub) и R10 (масштаб, фоновые PNG, C++).
Проекты и python.ini установщик сохраняет. Резервная копия — .ui-content-backups.

ПРИВЯЗКИ
Открой «Привязки элементов / новелла / видео…», выбери слайд и элемент.
Вкладка «Привязки»: слева / центр / справа / растянуть; сверху / центр /
снизу / растянуть. «Как на слайде» сохраняет прежнее поведение.
Отступ берётся из исходной позиции на слайде, в его единицах, и учитывает
общий масштаб UI. Область нажатия следует за элементом.
Пример для панели новеллы: растянуть по горизонтали + снизу.
Нажми «Сохранить элемент» перед выбором следующего элемента.
Кнопка «Привязать Blueprint…» сразу выбирает этот элемент в UI Blueprints.

ВИЗУАЛЬНАЯ НОВЕЛЛА
В PowerPoint сгруппируй рамку/рисунок и текстовый блок, затем обнови UI.
Импортируетcя исходная картинка группы и вариант без самого большого
текстового блока. Остальные рисунки и подписи группы сохраняются.
На вкладке «Визуальная новелла» включи «Использовать как поле новеллы».
Введи реплики, разделяя их пустой строкой. Одиночный перенос остаётся
внутри одной реплики. Выбери шрифт, размер, цвет и выравнивание. Сохрани.

Первая реплика видна сразу. Нажатие показывает следующую. Нажатие после
последней выставляет finished; последняя реплика остаётся на экране.
Можно включить повторение с первой или выключить автоматический клик.
Отдельная кнопка: UI Click → UI dialogue next, укажи ID поля реплик.
Активный Blueprint заменяет автоматическое действие: двойного перехода нет.
UI dialogue reset возвращает первую реплику. UI dialogue finished — bool
для Branch. UI set text меняет текст из Blueprint. Такие же методы есть
в Python: world.ui.dialogue_next(id, slide), dialogue_reset,
dialogue_finished, set_text(id, text, slide).

Переход при завершении можно сделать через Update → Branch с условием
UI dialogue finished → UI show slide / Load scene. Для разового действия
добавь после него UI dialogue reset либо отключи обработчик.
Для JSON есть onDialogueEnd, выполняющийся один раз при завершении.

Динамический текст использует один стиль: начальный шрифт/цвет выбранного
текстового блока или настройки редактора. Смешанное форматирование,
WordArt и эффекты отдельных букв не воспроизводятся. Слишком длинную
реплику раздели на несколько: текст уменьшается до минимального размера,
а то, что всё ещё не помещается, обрезается рамкой. Пустой текстовый блок
в PowerPoint заполни хотя бы временной репликой перед обновлением.

ВИДЕО
1. Встроенное в PPTX видео: вставь видео с компьютера именно внутрь
   презентации. При обновлении оно извлекается в assets/ui/<имя>/media.
   Ссылка на чужой локальный файл автоматически не читается.
2. Фигура со ссылкой YouTube: назначь фигуре гиперссылку на ролик.
   После обновления нажатие открывает этот ролик в браузере.
   Также можно задать ссылку на вкладке «Видео» в редакторе.

На вкладке «Видео» можно выбрать собственный файл: редактор скопирует его
в проект в фоне. Сохрани элемент. Есть автозапуск, повтор, громкость 0..1,
fit (вписать), fill (обрезать края), stretch (растянуть).
UI Click → UI play video запускает выбранный элемент; повторный вызов
для того же локального ролика переключает паузу. UI stop video закрывает его.
Смена слайда, скрытие элемента/UI и закрытие сцены останавливают ролик.
Не подключай UI play video к Update: это действие запуска/паузы, не тик.

Локальное видео: Windows 10/11, WPF/.NET Framework 4.8 и системные кодеки.
Один активный ролик на UI. Изображение и звук обрабатывает отдельный процесс;
главный поток движка не ждёт запуск/декодирование. Ошибки идут в Console.
Рекомендуемый исходник для проверки: обычный MP4 H.264/AAC. Поддержка
конкретного файла зависит от кодеков Windows. На Windows N могут требоваться
мультимедийные компоненты. Linux/Web не имеют этого видеобэкенда.

Видео — дочернее окно внутри viewport: без поворота, поверх GL-интерфейса.
На переходах оно скрыто. Размещай кнопки управления вне его прямоугольника.
Оно не входит в скриншот, считываемый из OpenGL, и не получает GL-постэффекты.
YouTube в этой версии — ссылка на браузер; ролик не скачивается и не рисуется
внутри игрового viewport. Автозапуск YouTube не выполняется.

ДОНАТЫ И ТРАНЗАКЦИИ
Открой «Донаты / транзакции…». Укажи свою платёжную ссылку https://.
В UI Blueprints есть шаблон «Открыть донат»: UI Click → Open donation.
Игрок подтверждает перевод на странице выбранного сервиса.
Само открытие браузера не считается оплатой.

Для автоматической проверки покупок есть клиент своего HTTPS-сервера:
Transaction start, Transaction is, Transaction paid once, Transaction reset.
Цена берётся сервером из product ID. Секретов магазина в игре нет.
Этот пакет не создаёт магазин/аккаунт и не содержит привязки к конкретному
платёжному провайдеру. Для подтверждённых транзакций нужен сервер,
реализующий TRANSACTIONS_R12.txt. Без него работают донаты по ссылке.

ПРИМЕР
Папка examples/UI_R12 — отдельный маленький проект.
В Hub выбери Open project и эту папку. Нажми Play. Кнопка «Дальше» связана
с Blueprint; при отключённых скриптах остаётся эквивалентное действие UI.
В нём есть реплики, нижняя растягиваемая панель и кнопка справа сверху.
В scripts/examples лежат отдельные графы доната и транзакции для настройки.
В примере нет настоящего платёжного адреса и нет автозапуска видео.

ПОВТОРНЫЙ ИМПОРТ И СБОРКА
Привязки, реплики, стиль текста и ручная настройка видео хранятся как
редакторские переопределения и сохраняются по стабильным ID фигур.
Картинки, текстовый слот и автоматически найденное видео обновляются.
Не удаляй связанную с Blueprint фигуру без снятия её привязки.
Export game переносит локальные видео, MyEngineVideo.dll и video_host.ps1
в Data. Если исключить обязательный файл видео, сборка сообщит об ошибке.
payments.json содержит только публичную ссылку и адрес своего сервера.

ПРОВЕРКА ЭТОГО ОБНОВЛЕНИЯ
Проверены: Python-тесты, реальные OpenGL отрисовка/клики с русским текстом,
разбор присланного PPTX (2 слайда, 8 элементов), извлечение тестового медиа,
сохранение настроек при обновлении, генерация Blueprint, неблокирующее
ожидание сети/текста, упаковка игры и откат установщика.
MyEngineVideo.dll скомпилирован против .NET Framework 4.8/WPF.
PowerShell проверен синтаксически и на имитации объектов COM.
Настоящий PowerPoint, Win32 GDI и воспроизведение WPF на Windows здесь
не запускались. После установки проверь импорт одной группы и одного MP4.
