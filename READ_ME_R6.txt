MyEngine 2.5 — UI BLUEPRINTS R6

Установка:
1. Закройте Editor, Hub и Viewport/игру.
2. Полностью распакуйте этот архив в отдельную папку.
3. Запустите INSTALL_UI_BLUEPRINTS_R6.cmd.
4. Выберите папку движка F:\Users\User\Desktop\MyEngine
   с файлами MyEngine2Editor.py и start_editor.cmd.
5. После успешной установки откройте редактор из этой папки или проект через Hub.

Для работающего MyEngine 2.5/R5 пересборка EXE не нужна.
Включены исправления PowerPoint, мыши и создание сцен R5.
Установщик делает резервные копии и проверяет установленные файлы.
Отчёт: UI_BLUEPRINTS_R6_install_report.json в папке движка.
Файлы пользовательских сцен, импортированного UI и картинок не заменяются.

Первое взаимодействие:
UI Blueprints → выбери слайд и фигуру → выбери шаблон действия →
Create / edit Blueprint → настрой узел → Apply to UI →
Save в главном окне редактора → Play.

Пример: UI Click → UI visible, галочка enabled выключена.
Другие действия: следующий слайд, выбранный слайд, видимость элементов,
включение/выключение слайдов, загрузка сцены и сообщение в Console.

Граф автоматически генерирует Python в регионе MYENGINE_BLUEPRINT
и прикрепляет обработчик к объекту UIController в сцене.
Повторно импортировать PowerPoint и редактировать JSON вручную не нужно.
Подробная инструкция: UI_BLUEPRINTS_R6.txt в папке движка после установки.

Проверено на присланном PowerPointUI.zip через настоящий Linux/Mesa runtime:
одиночное нажатие, скрытие интерфейса, переход на новую сцену и подготовка сборки.
Windows GUI в этой среде не запускался.
