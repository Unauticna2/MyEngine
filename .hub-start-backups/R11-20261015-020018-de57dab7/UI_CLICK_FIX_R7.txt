MyEngine 2.5 — UI CLICK FIX R7

Исправлено:
- Мышь во встроенном Viewport: учитывается главное окно редактора после SetParent.
  Самостоятельное окно игры тоже поддерживается. Чужие окна и диалоги не дают
  нажатиям пройти в игру.
- В обычных Blueprints доступны реальные ID элементов импортированного UI.
- Несуществующий ID выдаёт понятную ошибку при сохранении графа и в runtime.
- Save graph / Generate Python сохраняют текущее поле параметров без отдельного
  нажатия Apply parameters; переход к другому узлу также сохраняет правки.

Для данного MyGame:
В UI ID кнопки — play, а не 2. Активный UIController должен содержать цепочку
UI Click (slide=1, element=play) → LoadScene (scenes/room1.json).
Исправленный MyGame.zip уже содержит эту настройку. Из Floor убрана только
дублирующая привязка scripts/ui.py к несуществующему ID 2; сам скрипт сохранён.
Модели, физика, картинки, импортированный UI и сцена room1 не изменены.

Установка:
1. Закрой Editor, Hub и Viewport.
2. Полностью распакуй MyEngine2_UIClickFix_R7.zip в отдельную папку.
3. Запусти INSTALL_UI_CLICK_FIX_R7.cmd.
4. Выбери F:\Users\User\Desktop\MyEngine (папку с MyEngine2Editor.py).
5. Открой исправленный проект через Hub, сцену scenes/main.json, нажми Play.
   При нажатии и отпускании кнопки play должна открыться scenes/room1.json.

EXE пересобирать и PowerPoint импортировать заново не нужно.
Включены предыдущие исправления R4–R6. Старые обновления поверх R7 не ставить.
Установщик проверяет файлы и сохраняет резервную копию.
