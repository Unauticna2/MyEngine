MyEngine 2.5 — UI Blueprints R6

ПЕРВАЯ КНОПКА БЕЗ РЕДАКТИРОВАНИЯ JSON
1. Открой сцену с уже прикреплённым интерфейсом из PowerPoint.
2. Нажми UI Blueprints в верхней панели редактора.
   Та же кнопка доступна в Assets / extensions → PowerPoint / 2D interface.
3. Выбери слайд и фигуру из списка. У фигуры не обязан быть старый onClick.
4. Выбери шаблон первого действия: скрыть UI, следующий слайд,
   открыть конкретный слайд, загрузить сцену или сообщение в Console.
5. Нажми Create / edit Blueprint. Два узла уже соединены:
       UI Click → выбранное действие
6. Нажми узел действия. Справа укажи слайд/сцену или состояние enabled.
   Здесь есть обычные поля, списки и галочки. JSON для этих узлов не нужен.
   Apply parameters применяет параметры узла. Apply to UI также применяет
   текущую открытую форму параметров перед генерацией Python.
7. Нажми Apply to UI. Граф и Python сохраняются в scripts/ui;
   в сцену автоматически добавляется невидимый объект UIController со скриптом.
8. Вернись в главное окно, нажми Save и затем Play. Кликни фигуру в Viewport.

ПРОСТЫЕ ПРИМЕРЫ
- Спрятать меню: UI Click → UI visible; enabled выключен.
- Перейти дальше: UI Click → UI next slide. Нужен следующий включённый слайд.
- Открыть конкретный слайд: UI Click → UI show slide; выбери Slide ID.
- Загрузить уровень: UI Click → Load scene; выбери существующий JSON сцены.
- Проверить нажатие: UI Click → Log; напиши текст для Console.
- Выполнить цепочку: UI Click → Log → UI visible.
  Соединение: нажми выходной кружок next, затем входной кружок in другого узла.
  У выхода exec одно соединение. Несколько действий связываются цепочкой.

УЗЛЫ UI
UI Click: событие отпускания ЛКМ на той же фигуре, на которой началось нажатие.
UI visible: показать/скрыть весь прикреплённый UI.
UI show slide: открыть включённый слайд по ID, сбросив его время анимации.
UI next slide: открыть следующий включённый слайд; после последнего ничего не делает.
UI element enabled: показать/скрыть элемент и включить/выключить его нажатия.
UI slide enabled: разрешить/запретить слайд. Для показа используй UI show slide.
Load scene: запросить смену сцены после текущего кадра.

КАК СОХРАНЯЕТСЯ СВЯЗЬ
- Импортированный .ui.json и картинки не изменяются.
- В сцене хранится связь кнопки с графом и сгенерированным Python-скриптом.
- Повторно выбери ту же фигуру и Create / edit Blueprint, чтобы изменить её граф.
- Apply to UI обновляет существующий контроллер, в том числе после его переименования.
- Генератор заменяет только регион MYENGINE_BLUEPRINT. Пользовательский код
  за пределами этого региона сохраняется.
- Кнопка использует свой файл UI, Slide ID и Element ID. Одинаковые ID элементов
  на разных слайдах/в других файлах UI не смешиваются.
- В этом окне граф содержит одно событие UI Click для выбранной фигуры.
  Для другой фигуры создай отдельный граф из списка UI Blueprints.
- Активный обработчик Blueprint заменяет прежний onClick этой фигуры в Play.
  Для остальных фигур старые действия остаются рабочими. Если обработчик
  отключён, старый onClick снова доступен, поскольку исходный UI не изменён.
- Если выключен UIController, его скрипт или разрешение скриптов проекта/объекта,
  Blueprint не выполняется. Текущие разрешения автоматически не меняются.
- В режиме Edit события UI не выполняются. Проверяй клики в Play.
- Повторная генерация и перезагрузка скриптов не добавляют повторных обработчиков.
- Scripts/ui и связь контроллера сохраняются при обычной подготовке сборки.
  Если вручную исключить нужные Python-файлы из сборки, обработчик не загрузится.

ПРОВЕРКА ЭТОГО ОБНОВЛЕНИЯ
Проверены реальные ScriptBinding, генерация Python, одиночный клик, отмена
нажатия перетаскиванием наружу, разные слайды, разрешения, перезагрузка,
удаление контроллера, замена UI, сохранение и откат при ошибке записи.
На присланном PowerPointUI.zip проверены скрытие интерфейса и переход на
созданную сцену через настоящий Mesa/EGL-рендерер и Linux backend движка.
Windows GUI редактора и установщика в этой среде не запускался.
