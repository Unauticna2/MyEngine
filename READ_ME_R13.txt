MyEngine 2.5 — PowerPoint export fix R13

УСТАНОВКА
1. Закрой Editor, Hub и окно игры/Viewport.
2. Распакуй MyEngine2_PowerPointFix_R13.zip в отдельную папку.
3. Запусти INSTALL_POWERPOINT_FIX_R13.cmd и выбери папку движка:
   F:\Users\User\Desktop\MyEngine
4. Запусти MyEngine2.exe, открой проект через Hub.
5. Assets / extensions → PowerPoint / 2D interface.
   В заголовке должно быть UI TOOLS R13.
6. Оставь презентацию открытой в PowerPoint и повтори импорт.
   Если интерфейс уже импортирован, нажми «Обновить текущий UI из PowerPoint».

Пересборка EXE не нужна. Пакет включает предыдущие исправления R12.
Установщик проверяет файлы и сохраняет резервную копию в
.powerpoint-fix-backups. Проекты и python.ini не заменяются.
Отчёт установки: POWERPOINT_FIX_R13_install_report.json.

ЧТО ИСПРАВЛЕНО
Ошибка «Фигура заблокирована, ее поворот невозможен» возникала при записи
Rotation=0 даже в уже неповёрнутую фигуру. PowerPoint запрещает такую запись
для некоторых встроенных объектов и групп с ними. В предоставленном PPTX
это группа 9 на втором слайде, содержащая встроенный документ Word.

Теперь для нулевого угла импортёр вообще не записывает Rotation.
Восстановление угла выполняется только после успешного изменения.
Такая же проверка добавлена к экспорту копии группы без текста для новеллы.
Копия больше не перемещается без необходимости: текстовые координаты
вычисляются относительно неё, поэтому смещение при Duplicate не мешает.

Исходная открытая презентация не изменяется: экспорт использует снимок.
Обычные повёрнутые фигуры экспортируются с сохранением исходного угла
в интерфейсе. Настоящая ошибка изменения ненулевого заблокированного угла
не скрывается. Это исправление не снимает блокировки в презентации.

ПРОВЕРКА
PowerShell: выполнен производственный цикл экспорта на имитациях COM
с запрещённой записью Rotation, проверены восстановление после ошибки,
сохранение угла и очистка текстовой копии. Проверен синтаксис скрипта.
Проверены регрессии Python-импорта, обновления и UI-контента.
Windows PowerPoint здесь не запускался; реальный COM-экспорт не проверен.

Возможности интерфейса описаны в UI_CONTENT_R12.txt; в этой версии
актуальная отметка в заголовке окна — UI TOOLS R13.
