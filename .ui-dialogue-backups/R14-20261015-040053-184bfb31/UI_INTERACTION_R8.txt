MyEngine 2.5 — UI INTERACTION R8

Установка
1. Закрой MyEngine Editor, Hub и Viewport.
2. Полностью распакуй MyEngine2_UIInteraction_R8.zip в отдельную папку.
3. Запусти INSTALL_UI_INTERACTION_R8.cmd и выбери папку движка:
   F:\Users\User\Desktop\MyEngine
4. Открой проект снова. EXE пересобирать не требуется.
R8 включает исправления R4–R7. Старые патчи поверх R8 не устанавливать.

Обновить уже импортированный UI
Assets / extensions → PowerPoint / 2D interface →
«Обновить текущий UI из PowerPoint».
Презентация должна оставаться открытой. Учитываются несохранённые правки.
Для R8-импорта запоминается исходный открытый файл; для старого импорта
используется активная презентация. Если файл переехал/переименован, нажми
«Обновить из другого открытого .pptx…» и выбери этот файл.

Сохраняются путь .ui.json, Blueprint-привязки, пользовательские дополнительные
файлы в папке UI, выбранные в движке настройки анимаций и переходов.
Фигуры сопоставляются по PowerPoint Shape ID, слайды — по Slide ID.
Для старого импорта первое сопоставление слайда использует прежний номер;
сначала обнови импорт, затем переставляй слайды в PowerPoint.
При удалении кнопки, назначенной через UI Blueprints, обновление остановится
и сохранит прежний ресурс. Резервные копии находятся в папке проекта:
.myengine/ui-backups/
Фон слайда по-прежнему не импортируется.

Переходы между слайдами
В окне импорта или UI Blueprints есть кнопка «Переходы / анимации UI».
Выбери слайд: без перехода, плавное появление (fade), сдвиг (push).
Можно задать длительность, направление и автоматическую смену по времени.
Сохраняются настройки выбранного слайда и выбранного элемента.
PowerPoint fade/push/cut импортируются из временного снимка презентации.
Другие эффекты перехода заменяются fade с сообщением при импорте.
Поддерживается автоматическая смена слайда и смена по пустому месту.

Ноды Blueprint
- UIShowSlide: slide, transition, duration, direction.
- UINextSlide / UIPreviousSlide: следующий / предыдущий разрешённый слайд.
- transition=imported использует настройки целевого слайда.
- transition=none/fade/push переопределяет переход для этого вызова.
Пример: UI Click (slide=1, element=play) → UIShowSlide (slide=2,
transition=fade, duration=0.35).
Во время перехода нажатия на перемещающиеся элементы не выполняются.

Анимации кнопок
«Переходы / анимации UI» → выбери слайд и элемент → режим:
- Как в PowerPoint: исходная последовательность и триггеры.
- Автоматически один раз: запуск при входе на слайд.
- По нажатию на эту кнопку: до нажатия объект неподвижен; каждый щелчок
  перезапускает его эффекты.
- Автоматически по кругу: повтор всей последовательности элемента.
- Только узлом UI play animation: запуск из Blueprint UIPlayAnimation.

Галочка «Выполнить действие кнопки после анимации» позволяет сначала
проиграть нажатие, затем выполнить привязанный Blueprint/JSON onClick.
Для неё обычно выбирают режим «По нажатию». Пока анимация ожидается,
повторные клики не дублируют действие. Смена слайда отменяет ожидание.
Без галочки действие вызывается сразу: скрытие UI или загрузка сцены
сразу уберёт и саму кнопку.

Поддерживается PowerPoint-триггер «по щелчку на фигуре», в том числе когда
кнопка запускает эффект другого элемента. Встроенные эффекты импортера:
появление, затухание, масштаб, вылет, вращение. О неподдерживаемых эффектах
импортер сообщает; он не воспроизводит весь движок анимации Office.

Выход из программы
UI Click → QuitGame → Apply to UI → Save сцены → Play.
В редакторе QuitGame останавливает Play и восстанавливает редактируемую сцену.
В отдельной Windows/Linux игре запрашивает обычное закрытие приложения.
Из Python: self.world.quit().
Escape по умолчанию выключен в игре и больше не закрывает Viewport
в режиме редактирования. Настройки Game controls позволяют разработчику
явно включить Escape для своей игры.

Кавычки из PowerPoint
JSON понимает обычные двойные кавычки, а также “ ”, „ “ и « » в роли
разделителей строк. Пример:
{“myengine”:{“id”:“play”,“animationMode”:“click”}}
Обычные надписи не превращаются в код. Кавычки внутри корректных JSON-строк
сохраняются как текст. Другие синтаксические ошибки JSON выдаются с именем фигуры.

Проверка
Автоматические проверки: обновление/откат импорта, ID и привязки, JSON-кавычки,
PPTX XML переходов, режимы анимаций, ожидание перед действием, выход и Escape.
Через настоящий Linux/Mesa runtime проверены fade/push, загрузка прежнего
MyGame, QuitGame из кнопки и восстановление редактируемой сцены.
Windows GUI и установленный PowerPoint COM в этой среде не запускались.
