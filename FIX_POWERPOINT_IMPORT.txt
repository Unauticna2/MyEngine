Смотрите LIBREOFFICE_IMPORT.txt. Восстановление Microsoft Office не требуется.

MyEngine 2.5: исправление импорта PowerPoint

Обновление 2 — ошибка 0x80029C4A / TYPE_E_CANTLOADLIBRARY.
Эта ошибка означает, что не загрузилась COM-библиотека типов PowerPoint.
По одному сообщению нельзя определить, какая запись Office повреждена.
Исправление экспортёра не восстанавливает установленный Office автоматически.

Если ошибка сохраняется:
1. Сохраните документы и закройте приложения Office.
2. Windows 11 → Установленные приложения → Microsoft Office / Microsoft 365 →
   меню «…» → Изменить → Быстрое восстановление.
3. Если не помогло, используйте Онлайн-восстановление (нужен интернет).
4. Перезапустите редактор и повторите импорт.
Официальная инструкция:
https://support.microsoft.com/en-us/office/lifecycle/repair-an-office-application

Дополнительно исправлено:
- Ошибки Close / Quit больше не скрывают первоначальный сбой.
- Сообщение содержит этап экспорта и HRESULT вложенных исключений.
- Если экспорт завершился, а ошибка возникла только при закрытии PowerPoint,
  готовый интерфейс сохраняется, а ошибка закрытия показывается предупреждением.
- Движок даёт отдельное пояснение для 0x80029C4A в основном сбое.

Установка обновления:

1. Закройте редактор MyEngine.
2. Распакуйте MyEngine2_5_PowerPoint_fix.zip в папку MyEngine с заменой файлов.
   engine_pptx_import.py должен лежать рядом с engine_runtime.py.
   powerpoint_export.ps1 должен лежать в подпапке tools.
3. Откройте редактор и повторите импорт 2DInteface.pptx.
   Пересобирать EXE не нужно. Для импорта нужен установленный Microsoft PowerPoint.

Исправления:
- Запуск встроенного экспортёра с -ExecutionPolicy Bypass только для дочернего
  процесса PowerShell. Настройки в реестре не меняются. MachinePolicy/UserPolicy
  по-прежнему имеют приоритет; при блокировке выводится отдельное сообщение.
- Ошибки до запуска скрипта читаются с учётом OEM-кодировки Windows.
- JSON можно писать в Alternative Text или целиком в тексте фигуры:
  {"myengine":{"id":"play","onClick":[{"action":"ui","enabled":false}]}}
- При втором варианте JSON скрывается в экспортированной картинке кнопки.
  Оригинальная презентация не изменяется. Для надписи «Играть» на кнопке
  напишите её в самой фигуре, а JSON перенесите в Alternative Text.
- Alternative Text имеет приоритет. Обёртка myengine обязательна для JSON
  в обычном тексте. Нажатие кнопки из примера отключает весь интерфейс.

Проверка: автоматические Python-тесты запуска/ошибок/очистки файлов и действия
ui.enabled=false. PowerPoint COM и экспорт PNG нужно проверить в Windows:
эта среда не содержит Windows и Microsoft Office.

Если администратор ограничил выполнение скриптов групповой политикой, требуется
одобренный/подписанный экспортёр. Исправление не меняет такие ограничения.
