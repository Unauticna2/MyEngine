MYENGINE R16 — КНОПКА ПОКУПКИ БЕЗ ОТКЛЮЧЕНИЯ UIController

Закрой редактор и игру. Распакуй MyEngine2_Commerce_R16.zip поверх папки
движка с заменой файлов. Архив включает генератор R15 и исправление R16.
Подходит поверх R14 или R15. Пересборка EXE для этого исправления не нужна.
Сцены и пользовательские scripts/ui/button_*.py менять не требуется.

ПРИЧИНА ОШИБКИ
Transaction start('deluxe', 'purchase') работал в API-режиме, но checkoutApi
был пустым. Генерация ZIP ещё не означает, что сайт опубликован и подключён.
R15 ошибочно отключал UIController целиком при незаполненных настройках.

ЧТО ИСПРАВЛЕНО
Отсутствие сайта, ссылки доната, несовпадение ID товара и повреждённые
настройки оплаты теперь выдают PAYMENT NOT READY и сохраняют UIController.
Текущая цепочка Blueprint прерывается до подключения: следующие узлы
не выполняются, успешная оплата не выставляется. Другие кнопки работают.
Настоящие ошибки Python по-прежнему отключают ошибочный скрипт.
После отклонённого клика новый клик перечитывает настройки, если ещё нет
транзакций. Для уже существующих транзакций адреса остаются прежними.

ЧТО НАДО СДЕЛАТЬ В ПРОЕКТЕ
1. Останови Play. Assets / extensions → Коммерция / генератор сайта.
2. Вкладка «Сайт и кнопки»: вставь HTTPS-адрес своего опубликованного сайта.
3. «Сохранить и подключить сайт к кнопкам». У сайта ID товара deluxe.
4. Снова Play и нажми свою кнопку. Старый Blueprint пересоздавать не надо.

Если сайт ещё не опубликован: сначала экспортируй ZIP, опубликуй его
на Render и получи адрес. Его нельзя заменить произвольной ссылкой.
Адрес в поле Checkout API нужен только отдельному серверу проверки оплаты.
Адрес обычного сайта вставляется в поле «Опубликованный адрес сайта».
Теперь «Сохранить настройки» тоже подключает введённый адрес, если
не выбран настроенный API-сервер. Внизу окна виден статус подключения.

В PROJECT/payments.json для сайта будут:
checkoutMode: site
checkoutSite: твой реальный HTTPS-адрес
siteProduct: deluxe

Никаких платежей при проверке не выполнялось. Проверено 33 Python-тестами,
включая настоящий сгенерированный обработчик UI и его повторный вызов
после исправления настроек. Windows-окно и нативный EXE здесь не запускались.
