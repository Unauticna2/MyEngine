MYENGINE 2.5 — UI FIX R3 / ИМПОРТ ИЗ ОТКРЫТОГО POWERPOINT

УСТАНОВКА
Рекомендуется отдельный MyEngine2_UIFix_R3.zip: распакуйте целиком, запустите
INSTALL_UI_FIX_R3.cmd и выберите папку движка с MyEngine2Editor.py.
Он сохранит резервную копию и проверит все заменённые файлы по SHA-256.
После запуска нового редактора заголовок диалога должен начинаться с UI FIX R3.
Внизу показан путь загруженного модуля, галочка фона находится вверху.
Обычная установка архива с файлами (без установщика):
1. Закройте редактор MyEngine (PowerPoint закрывать не нужно).
2. Распакуйте MyEngine2_5_PowerPointOpen_update.zip в папку движка
   рядом с MyEngine2Editor.py, с заменой файлов.
   Патч подходит к 2.5 до и после LibreOffice-обновления.
3. Перезапустите редактор. EXE версии 2.5 пересобирать не требуется.
   LibreOffice, setup_libreoffice.cmd и дополнительные pip-пакеты не нужны.
   Старые PowerPoint_fix/LibreOffice_update поверх этого патча не устанавливайте.

ИМПОРТ
1. Откройте локальную презентацию .pptx в обычном Microsoft PowerPoint.
   Если окон несколько — выберите окно нужной презентации.
2. Переключитесь в MyEngine: Assets / extensions → PowerPoint / 2D interface.
3. Нажмите Import from open PowerPoint… и задайте новое имя папки UI.
4. Результат автоматически подключится к сцене:
   assets/ui/<имя>/interface.ui.json + картинки отдельных фигур (без фона слайда).
   Для проверки кнопок включите Play. PNG/JSON не требуют Office в игре.

ФОН СЛАЙДА
Фон выключен по умолчанию в самом проигрывателе и редакторе, в том числе
для ранее импортированных интерфейсов. Фоновая текстура не загружается и
не рисуется. Ничего править или повторно импортировать не нужно.
После установки патча полностью перезапустите редактор и его Viewport/Play.
В диалоге PowerPoint / 2D interface есть галочка:
«Показывать фон слайда / Show slide background». По умолчанию она снята.
Она управляет сохранённым фоном текущей сцены, если фон уже имеется в UI.
Смена галочки обновляет предпросмотр; сохраните сцену для следующего запуска.
Новые импорты по-прежнему вообще не экспортируют фон слайда.
Заливка и оформление самих кнопок/фигур сохраняются.
Python: ui.show_background = True/False; или world.load_ui(path, show_background=False).

КАК РАБОТАЕТ
Windows PowerShell 5.1 подключается через Marshal.GetActiveObject.
Новая копия приложения PowerPoint не запускается. Импортёр не вызывает Quit.
ActivePresentation сохраняется через SaveCopyAs во временный .pptx: в снимок
попадают текущие несохранённые правки. Исходный документ не сохраняется,
не переименовывается, не закрывается и его признак Saved не меняется.
Видимость, подписи и повороты меняются только в снимке. Он удаляется после
экспорта; исходный файл и окно остаются. Во время импорта не редактируйте снимок.
Импорт выполняется в рабочем потоке редактора через отдельный STA-процесс.
Одновременные импорты блокируются, GUI не ждёт синхронно COM-вызовов.

JSON
Замещающий текст (Alternative Text) фигуры либо весь текст фигуры:
{"myengine":{"id":"play","onClick":[{"action":"ui","enabled":false}]}}
JSON из текста скрывается только в экспортируемой копии фигуры.
Для обычной надписи «Играть» поместите JSON в Alternative Text.
Сохраняются действия переключения слайдов/сцен/скриптов, JSON-анимации и
основные Appear/Fade/Fly/Zoom/Spin. Сложные эффекты могут отличаться; читайте
предупреждения. Медиа выгружаются статично. Для анимации кадров — frames/fps;
файлы frames ищутся относительно папки исходной презентации.

ЕСЛИ ОШИБКА
Если PowerPoint не найден, откройте .pptx, переключитесь в другое окно и повторите.
PowerPoint и редактор запускайте под одним пользователем с одинаковыми правами.
Используется powershell.exe, не PowerShell 7/pwsh. Глобальная execution policy
не изменяется. Политика организации всё ещё может запретить запуск ps1.
Несохранённую ни разу/облачную презентацию сначала сохраните как локальную .pptx.
Режим защищённого просмотра может не давать доступа к ActivePresentation.
При ошибке выводится конкретный этап и HRESULT, без подмены ошибкой очистки.
При таймауте 300 секунд прекращается только дочерний экспортёр, а не PowerPoint.
Может остаться временная презентация MyEngine2-Export-*.pptx: закройте её без
сохранения. Оригинал не закрывайте. Временный файл лежит в
%TEMP%/MyEngine2-PowerPoint-<случайный идентификатор>/.

ПРОВЕРКА
На компьютере пользователя GetActiveObject уже прочитал 2DInteface.pptx и 1 слайд.
Проверены транзакционная запись, ошибки/таймауты, отдельные аргументы путей,
копирование кадров, защита существующих ресурсов и действие кнопки UI.
Исправление проверено в настоящем Mesa/OpenGL на старом интерфейсе с фоном:
за кнопкой виден игровой framebuffer, запрос фоновой текстуры отсутствует.
Исходный UI JSON не изменяется; нажатие кнопки продолжает работать.
Windows PowerPoint здесь не установлен: полный COM-экспорт на нём не запускался.
Подключение обходит сбой запуска COM-сервера, но последующие COM-операции
SaveCopyAs/Open/Export тоже зависят от работоспособности установленного Office.
