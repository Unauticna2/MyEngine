MYENGINE R21 — ТВОЙ ANDROID КАК SMS-ОТПРАВИТЕЛЬ

Владелец: зарегистрированный сертификат + свой номер + отдельный пароль.
SMS себе не отправляется. Пароль задаётся локально через setup_owner.cmd
в папке сервера; в Render хранится только его scrypt-хеш с солью.

Остальные игроки: зарегистрированный сертификат + привязанный телефон +
одноразовый код. Код отправляет твой Android через выбранную SIM.
Render хранит реестр и очередь, проверяет пароль/код и сообщает результат игре.

УСТАНОВКА ОБНОВЛЕНИЯ
Закрой редактор и игру. Скопируй содержимое engine-update из комплекта R21
в F:\Users\User\Desktop\MyEngine с заменой файлов. Сам проект MyGame
обновление не перезаписывает. Для R14–R20 пересборка EXE не нужна;
уже экспортированную игру нужно экспортировать повторно.
Это накопительное обновление R14 → R21, включая металл R20.

НАСТРОЙКА
В комплекте MyEngine_SMS_Android_R21.zip:
  server/ — сервер Render и подробный README_RU.txt; начни с setup_owner.cmd.
  android-source/ — исходники приложения и инструкция для сборки.
  engine-update/ — накопительное обновление редактора и runtime.
  START_HERE_RU.txt — короткий порядок запуска.
Готовый APK предоставляется отдельно и включён в android-source.

В редакторе:
Коммерция / генератор сайта → Сайт и кнопки → Проверка игрока / SMS.
Отсюда можно экспортировать сервер и сохранить APK.
Укажи HTTPS-адрес сервера, включи «Требовать проверку игрока…», сохрани.
Шаблон кнопки «Войти после проверки игрока / SMS» остаётся совместимым:
Player verified возвращает true после SMS игрока либо пароля владельца.
Access unlocked тоже использует серверную проверку при identityRequired=true.
Покупка/банковский платёж от такой проверки не становятся подтверждёнными.

ЗАПУСК
Настрой OWNER_*, базу и сервер по server/README_RU.txt, зарегистрируй сертификаты.
Для входа владельца телефон-шлюз может быть выключен: нужен сервер и пароль.
Для других игроков включи SMS_ENABLED=true, запусти приложение на телефоне.
На телефоны игроков APK ставить не нужно.
Пароль владельца не присылай в чат и не помещай в игровой проект.

ПРОВЕРЕНО
Сервер: правильный/неправильный пароль, привязка номера и playerId, ограничения
попыток, выдача задания только одному устройству, повторные запросы, отзыв,
истечение кода, ошибки/неопределённость отправки, отсутствие доступа до ввода кода.
Страница: SMS, очередь и пароль владельца; очистка чувствительных полей.
APK: Java-код скомпилирован, DEX и ресурсы собраны SDK 35, подписи v2/v3 проверены.
Реальная SIM, энергосбережение конкретного телефона и Render/PostgreSQL пока
не проверены. Android 8.0+; приложение запускается и останавливается явно.
Подробности лимитов, сброса/отзыва и хранения данных — в README сервера.
