MyEngine 2.5 R27 — build 2.5-R27-20261017.3

УСТАНОВКА
Закрой редактор и игру. Распакуй обновлённый MyEngine_Update_R27.zip
в папку движка поверх R26/R27 с заменой файлов, затем открой редактор.
Пересобирать уже существующий R26/R27 EXE не нужно.

МЕНЮ ПКМ
Правый щелчок по свободному месту Hierarchy:
  Create -> Cube / Voxel / Empty / Liquid
  Create -> Light -> Directional / Point / Spot Light

Правый щелчок по объекту в Hierarchy выбирает этот объект.
Правый щелчок в Inspector использует текущий выбранный объект.
В обоих случаях доступны:
  Create
  Add component -> Box Collider / Mesh Collider / Voxel Collider
  Add component -> Rigidbody / Liquid
  Duplicate / Delete

Прежние нижние кнопки создания и добавления компонентов убраны.
В Play изменение сцены через эти команды блокируется, как и раньше.
Добавление компонента применяется сразу; Ctrl+S сохраняет сцену.
При добавлении Rigidbody без Collider создаётся и Box Collider,
который использует физика. Повторное добавление Rigidbody не сбрасывает
его настройки. Смена типа Collider сохраняет размеры, слои и флаги.
Жидкость должна быть отдельным объектом без Collider/Rigidbody/VOX/4D.
Voxel Collider требует воксельную модель. Для динамического тела нужен
Box Collider; Mesh/Voxel Collider используется статически/кинематически.

ГАЛОЧКА IS TRIGGER
Выбери объект. Под его именем и Active/Visible находится блок Collider:
  Enabled — включить/отключить коллайдер;
  Is Trigger — включить/отключить режим триггера;
  box / mesh / voxel — тип коллайдера.

Если Collider ещё нет, поля неактивны и показана подсказка:
ПКМ -> Add component -> Box Collider (или подходящий другой тип).

Is Trigger применяется СРАЗУ при щелчке — кнопка Apply changes для этой
галочки не требуется. Ctrl+S сохраняет результат в сцену. Undo/Redo
восстанавливает и значение в сцене, и отображение галочки.

Is Trigger включён: объект пропускает другие тела и вызывает
OnTriggerEnter / OnTriggerStay / OnTriggerExit в прикреплённом блюпринте.
Is Trigger выключен: обычные столкновения и OnCollision*.
У второго объекта тоже должен быть Collider. Для твёрдого столкновения
хотя бы одному объекту нужен обычный некинематический Rigidbody.

Размер, центр, W-толщина, слои и дополнительные параметры сохранены
в раскрываемом Advanced shape / layers (JSON). Для обычного переключения
Is Trigger редактировать JSON не нужно. Изменения расширенного блока
и остальных полей Inspector применяются кнопкой Apply changes.

Пример событий: scripts/physics_events.blueprint.json.
Ранее созданные графы после добавления события нужно Generate Python
в тот же .py и прикрепить .py к объекту с Collider.
