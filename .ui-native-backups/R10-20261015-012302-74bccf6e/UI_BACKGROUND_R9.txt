MyEngine 2.5 — UI TOOLS R9
Исправление повторного включения фона PowerPoint

УСТАНОВКА
1. Закрой MyEngine Editor, Hub и окно игры / Viewport.
2. Полностью распакуй MyEngine2_UIBackground_R9.zip.
3. Запусти INSTALL_UI_BACKGROUND_R9.cmd.
4. Выбери папку движка, содержащую MyEngine2Editor.py и start_editor.cmd.
   Для твоей установки: F:\Users\User\Desktop\MyEngine
5. Запусти start_editor.cmd из этой папки. В окне импорта UI должно быть UI TOOLS R9.
Пересборка EXE не требуется. R9 включает исправления R4–R8.
Установщик сохраняет заменяемые файлы в .ui-background-backups внутри движка.

КАК ВЕРНУТЬ ФОН
Открой исходную презентацию .pptx в PowerPoint.
В движке открой окно PowerPoint / 2D interface и включи
«Показывать фон слайда / Show slide background».
Если галочка уже стоит, выключи и включи её снова.
Если фон раньше не импортировался, редактор обновит UI из PowerPoint,
загрузит фон и включит его после успешного импорта.
Если возникла ошибка, редактор покажет её и сохранит предыдущее состояние галочки.
Также можно нажать «Обновить текущий UI из PowerPoint» с включённой галочкой.

После первой загрузки переключение галочки не требует PowerPoint:
фон сохраняется вместе с UI, выключение только скрывает его.
Для изменений в презентации нажимай «Обновить текущий UI из PowerPoint».
Эта команда обновляет ранее импортированные фоны даже при выключенной галочке,
чтобы следующее включение показывало актуальную картинку.
При новом импорте с выключенной галочкой фон не экспортируется.

ИСПРАВЛЕНИЕ
Раньше галочка меняла только видимость: импортер не создавал изображение фона.
Теперь PowerPoint экспортирует отдельный фон на временной копии презентации,
скрывая фигуры слайда на время экспорта. Кнопки остаются отдельными элементами UI.
Сохраняются собственный/унаследованный фон и оформление образца слайда.
Оригинальная презентация не редактируется и не закрывается.
При обновлении сохраняются стабильные ID и настройки Blueprints из R8.
При ошибке экспорта предыдущие файлы UI остаются на месте.

ПРОВЕРКА
Проверены импорт/обновление через имитацию границы PowerPoint, обработчики
галочки, откат ошибки, смена сцены во время импорта и обновление кеша текстур.
Реальный рендер OpenGL: фон включён -> выключен -> включён;
после замены PNG под тем же именем отображается новая картинка.
PowerPoint COM и окна Windows на этой Linux-машине не запускались.

Используемые API Microsoft:
https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slide.export
https://learn.microsoft.com/en-us/office/vba/api/powerpoint.shape.visible
