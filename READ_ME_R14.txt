MyEngine 2.5 — UI DIALOGUE R14

УСТАНОВКА
1. Закрой Editor, Hub и окно игры/Viewport.
2. Распакуй MyEngine2_UIDialogue_R14.zip в отдельную папку.
3. Запусти INSTALL_UI_DIALOGUE_R14.cmd и выбери папку движка:
   F:\Users\User\Desktop\MyEngine
4. Запусти MyEngine2.exe и открой проект.
5. Assets / extensions → PowerPoint / 2D interface:
   в заголовке должно быть UI TOOLS R14.
6. Открой «Привязки элементов / новелла / видео…» → «Визуальная новелла».

Повторный импорт PowerPoint и пересборка EXE для этого изменения не нужны.
Пакет содержит предыдущие исправления, включая R13.
Проекты и python.ini не заменяются. Резервная копия установщика:
.ui-dialogue-backups. Отчёт: UI_DIALOGUE_R14_install_report.json.

ЧТО ОЗНАЧАЛО СТАРОЕ СООБЩЕНИЕ
«Dialogue: 1..1000 text entries, up to 4096 characters each» объединяло
несколько причин: пустой список реплик, больше 1000 реплик, реплика длиннее
4096 символов, неверный тип данных JSON или нулевой символ в тексте.
По одному этому сообщению нельзя было определить конкретную причину.

Теперь под полем видны количество реплик, длина самой длинной реплики
и точная причина, если данные не подходят. Сообщение появляется сразу
при изменении текста или галочки. При загрузке файла ошибка также содержит
ID слайда и элемента. Ограничения остаются прежними; текст не обрезается.

КАК ВВЕСТИ РЕПЛИКИ
Включи «Использовать как поле новеллы» и введи хотя бы одну реплику:

Привет! Это первая реплика.

Это вторая реплика.

Пустая строка разделяет реплики. Строка с пробелами/табуляцией тоже
считается пустой. Обычный перенос строки остаётся внутри одной реплики.
Поддерживаются переносы LF, CRLF и CR.

Если нужна только привязка элемента или видео, выключи галочку новеллы.
Если сообщение указывает длинную реплику, раздели именно её пустой строкой
на несколько реплик. При отклонённом сохранении файл UI не изменяется.

ПРОВЕРКА
Выполнены тесты разбора переносов, пределов 1000 реплик/4096 символов,
диагностики ошибок, сохранности файла и перехода к следующей реплике
по клику после сохранения. Проверены регрессии UI R12 и импорта PowerPoint.
Проверен установщик, включая резервную копию и откат при ошибке.
Окно Tk/Windows и PowerPoint в этой среде не запускались.
