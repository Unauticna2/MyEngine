MYENGINE R17 — НЕСКОЛЬКО ТОВАРОВ НА ОДНОМ САЙТЕ

УСТАНОВКА
Закрой редактор и игру. Распакуй MyEngine2_Commerce_R17.zip поверх папки
движка с заменой файлов. Подходит поверх MyEngine 2.5 R14 / R15 / R16.
Включены генератор R15, исправление отключения UIController R16 и каталог.
Пересобирать EXE не требуется. Сцены и пользовательские button_*.py
этот архив не заменяет. Полный архив исходников MyEngine2_5.zip тоже обновлён.

ОДИН АДРЕС — КАТАЛОГ
Донат-ссылка и адрес Render остаются одними и теми же. На сайте теперь
карточки всех товаров, а ниже форма оплаты выбранного товара.
Можно продавать игру, Deluxe и дополнения на одном сайте.
Кошелёк ЮMoney, поддержка и настройки разработчика общие.
Цена, ID, название, описание и условия активации отдельные для каждого товара.
Одна операция оплачивает один выбранный товар; общей корзины нет.

КАК ДОБАВИТЬ ТОВАР
1. Assets / extensions → Коммерция / генератор сайта → вкладка «Товары».
2. Нажми «+ Добавить товар». Заполни название, уникальный ID (например dlc1),
   цену, описание и порядок активации.
3. Можно дублировать выбранный товар или удалить лишний. Последний товар
   удалить нельзя. Каталог поддерживает от 1 до 100 товаров.
4. При выборе другого товара введённые поля сохраняются в текущем черновике.
   Чтобы записать всё в проект, нажми «Сохранить настройки».
5. «Экспорт сайта для Render…» создаст один ZIP со всем каталогом.
   Замени содержимое прежнего репозитория сайта новыми файлами.
   Настройки Render остаются: node scripts/build-static.mjs → dist.
6. После обновления сайта во вкладке «Сайт и кнопки» нажми «Сохранить
   и подключить сайт к кнопкам». Это обновит список ID товаров в игре.
   Затем останови и снова запусти Play.

КНОПКИ В ИГРЕ
Для новой кнопки UI Blueprints: действие «Создать транзакцию», ниже выбери
товар из списка. Новый узел получает product и key равными ID этого товара.
Список перечитывается при раскрытии, так что после добавления товара
достаточно сохранить коммерческие настройки.
Для существующего Blueprint открой граф и укажи параметры вручную:

Игра:        product = game     key = game
Дополнение:  product = dlc1     key = dlc1
Deluxe:      product = deluxe   key = deluxe

Это примеры: используй ID, которые действительно создал в каталоге.
Разным товарам нужны разные key, иначе их состояния смешались бы.
R17 сообщает о совпавшем ключе, сохраняя UIController рабочим.
Одинаковые кнопки одного товара могут использовать один key для защиты
от повторного открытия того же заказа. Transaction reset действует как раньше.

ССЫЛКИ И ОПЛАТА
Transaction start('dlc1','dlc1') открывает тот же сайт с ?product=dlc1
и уникальным requestId. Из списка товаров на сайте можно перейти к другому;
при этом метка прежнего игрового запроса не переносится на новый товар.
Возврат с ЮMoney сохраняет выбранный product. Неизвестный ID блокирует оплату
и предлагает выбрать товар из каталога, а не подставляет другой товар.
Цена берётся из конфигурации выбранного товара; URL не меняет сумму/кошелёк.

Каждый ID имеет стабильный короткий код в метке платежа:
из игры — ME-<код товара>-<requestId>;
с сайта — MP-<код товара>-<ID игрока>-<случайная часть>.
Таблица ID, названий, цен и кодов есть в README экспортированного сайта.
Метка укладывается в 64 символа, даже при длинном ID товара.
При изменении ID товара меняются его ссылки и код — обнови связанные кнопки.

СОВМЕСТИМОСТЬ
Старые commerce.json и config.js автоматически становятся каталогом из
одного товара. Кошелёк, цена и проверка разработчика сохраняются.
Кнопка «Мой MyEngine Deluxe · 10 ₽» загружает прежний пресет из одного товара.
Импорт ZIP/config.js нового сайта переносит весь каталог.
Старые payments.json с siteProduct поддерживаются; R17 записывает также
siteProducts со всеми подключёнными ID. API-режим остаётся прежним.

Сертификат разработчика теперь содержит ID и название выбранного товара.
Как раньше, это бесплатная локальная выдача: payment.status=not_required.
Обычная оплата подтверждается вручную; автоматическая проверка требует
отдельного Checkout API. Публикация на Render не выполняется при экспорте.

ПРОВЕРЕНО
39 Python-проверок и 21 JavaScript-сценарий. Проверены миграция, редактор
каталога, сохранение/импорт/экспорт, маршрутизация разных игровых кнопок,
уникальность ключей, цена выбранного товара, переходы между товарами,
возврат с оплаты и сертификат нужного дополнения. Сборка сайта Node прошла.
Реальных платежей не было. Windows-редактор и внешний браузер не запускались.
