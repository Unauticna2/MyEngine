MyEngine 2.5 — MOUSE FIX R4

Исправление:
ctypes.ArgumentError: expected LP_Point instance instead of pointer to Point

Причина: интерфейс слайдов и редактор осей использовали разные ctypes-типы
Point и меняли сигнатуру общей функции GetCursorPos при обработке кадра.
Теперь используется общий модуль engine_wininput.py; сигнатуры задаются
при инициализации. Проверяются ошибки получения координат окна и мыши.

Установка:
1. Закройте MyEngine Editor, Hub и Viewport/игру.
2. Распакуйте ВЕСЬ этот ZIP в отдельную папку.
3. Запустите INSTALL_MOUSE_FIX_R4.cmd.
4. Выберите папку движка: F:\Users\User\Desktop\MyEngine
   В ней должны находиться MyEngine2Editor.py и start_editor.cmd.
5. Дождитесь сообщения MOUSE FIX R4: установлено и проверено.
6. Запустите start_editor.cmd из указанной папки движка.

Установщик проверяет файлы и сохраняет резервную копию заменяемых файлов.
Отчёт: MOUSE_FIX_R4_install_report.json в выбранной папке движка.
Пересборка EXE не требуется. Сцены и импортированные ресурсы не меняются.
Предыдущие исправления PowerPoint и отключения фона входят в обновление.
Название окна импорта остаётся UI FIX R3 — это версия его интерфейса.

Проверено: точное воспроизведение прежней ошибки через ctypes;
последовательный опрос UI и gizmo после исправления; нажатие кнопки UI;
потеря фокуса и ошибки WinAPI; перемещение/масштаб/поворот осей.
Проверки выполнены с ctypes-функциями, имитирующими user32.
Настоящий Windows Viewport и GUI установщика в этой среде не запускались.
