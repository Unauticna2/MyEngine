Закрой редактор и окно игры. Распакуй MyEngine_Update_R23.zip прямо в папку
установленного MyEngine с заменой файлов: туда, где MyEngine2Editor.py,
engine_runtime.py и папка shaders. Не в Documents/MyEngine Projects/MyGame.

Это патч для установленного R21/R22. Полный MyEngine2_5.zip также обновлён.

1. РЕГИСТРАЦИЯ
В окне «Проверка игрока / SMS» появились кнопки открытия регистрации и управления.
Экспорт сервера теперь включает /register и /moderation.
Обнови файлы своего существующего сервера Render отдельно — установка движка
не обновляет уже опубликованный сайт. Готовый отдельный архив:
MyEngine_PlayerIdentity_Server_R23.zip.
Вход владельца использует прежние номер и пароль. Новые режимы:
«Закрыта», «Свободная — после SMS», «По заявке — с моим одобрением».
В режиме заявок игрок сам отправляет письмо #verify со своей почты.
Resend и API-ключи не нужны. Сайт заполняет получателя, тему и текст письма.
Полный порядок: templates/player-identity/README_REGISTRATION_R23.txt.
Android-приложение R21 менять не нужно. Существующую базу / ключи сохраняй.

2. НЕДОРОГИЕ ОТРАЖЕНИЯ
Убраны отражения упрощённых белых параллелепипедов и отдельное выдуманное небо.
Теперь отражается захват реальной сцены: геометрия моделей, текстуры, цвета,
воксели и тот же skybox / солнце, которые настроены у сцены.
Roughness размывает захват; Metallic определяет металлический материал.
Настройки: «Shadows / sun» → «Reflections».
По умолчанию: 256 пикселей на сторону, 1 сторона каждые 0,05 секунды,
до 128 объектов в радиусе 40. Полный захват обновляется примерно за 0,3 секунды
при достаточном FPS. На слабом ПК выбери 128 и интервал 0,1 секунды.
Новая картинка публикуется только после всех 6 сторон — без частично
перезаписанного неба. Отражения используют реальное разрешение и лимит draw calls.
Это одна общая локальная cubemap около ближайшего металлического объекта,
а не полноценная трассировка лучей. Сам объект-зонд не отражает себя,
повторные зеркальные отражения не рассчитываются; возле других отражающих
моделей возможна неточность положения отражения. Движение обновляется по частям.
Для белого металла начни с Metallic=1, Roughness=0.15, Reflection strength=0.7.
Светлые низкополигональные модели остаются гранёными согласно нормалям их mesh.
Старый maxObjects сохранён для чтения старых сцен; бюджет теперь задаёт maxDraws.

3. ВВОД В ИНСПЕКТОРЕ WINDOWS
Редактор при старте сам запускает системный ctfmon.exe один раз, без изменения
реестра и автозагрузки. Вручную запускать его через Диспетчер задач не требуется.
При клике в текстовое поле восстанавливается настоящий фокус Windows после
перехода из отдельного окна viewport. Фокус фоновых окон не перехватывается.
Повторное событие выбора того же объекта больше не пересоздаёт все поля
инспектора и не уничтожает текущее поле ввода.
После обновления проверь: клик в viewport → клик в Name / Position → ввод,
переключение русской / английской раскладки, Alt+Tab и возврат в редактор.
На настоящем Windows GUI здесь тест не выполнялся: проверена логика фокуса
и вызовов Win32 на заглушках. Если проблема повторится, нужен новый лог
и описание, какое именно поле перестало принимать ввод.

ПРОВЕРЕНО
Базовая версия R23: 330 тестов без ошибок, 3 платформенных проверки пропущены.
R23.1: отдельно проверены регистрация, подготовка письма и прежний вход игроков.
Headless OpenGL/Mesa: захват реальной сцены, цвета / текстуры, Roughness,
поэтапное обновление cubemap, сохранение GL viewport и компиляция fallback GLSL.
Существующие тесты входа владельца, Android-шлюза и сертификатов проходят.
Публикация на Render, реальный Windows ввод и отправка SMS/писем не выполнялись.
