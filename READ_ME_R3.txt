MYENGINE 2.5 — UI FIX R3

1. Закройте MyEngine Editor, Hub и окно игры/Viewport. PowerPoint оставьте открытым.
2. Распакуйте ВЕСЬ MyEngine2_UIFix_R3.zip в отдельную папку в любом месте.
3. Запустите INSTALL_UI_FIX_R3.cmd.
4. Выберите папку ДВИЖКА, где находится MyEngine2Editor.py и start_editor.cmd.
   На присланном скриншоте движок работает из F:\Users\User\Desktop\MyEngine.
   Не выбирайте папку проекта MyGame или assets/ui.
5. Дождитесь «UI FIX R3: установлено и проверено ... файлов».
6. Запустите start_editor.cmd из той папки, которую показал установщик.
   Assets / extensions → PowerPoint / 2D interface.

ПРИЗНАКИ НОВОЙ ВЕРСИИ
Заголовок диалога: UI FIX R3 — PowerPoint / 2D interface.
Галочка «Показывать фон слайда / Show slide background» находится в самом верху.
По умолчанию фон старых и новых интерфейсов не рисуется и не загружается на GPU.
Внизу окна показан полный путь загруженного engine_settings_ui.py.
Если заголовок другой — это другой/ещё не перезапущенный экземпляр редактора.
Повторный импорт и правка JSON для старого интерфейса не нужны.

ПРОВЕРКА И РЕЗЕРВНАЯ КОПИЯ
Установщик проверяет SHA-256 каждого файла до и после копирования.
Предыдущие версии заменяемых файлов хранятся в .ui-fix-backups/R3-... внутри движка.
Отчёт: UI_FIX_R3_install_report.json там же.
При ошибке копирования уже заменённые файлы восстанавливаются из резервной копии.
Папки проектов, пользовательские интерфейсы, сцены, python.ini и EXE не удаляются.
Убираются только кэши .pyc заменяемых Python-модулей.
Для проверки установленного набора без изменений:
  py -3 install_ui_fix_r3.py --target "F:\Users\User\Desktop\MyEngine" --verify-only

ПРОВЕРЕНО
Рендер непосредственно присланного PowerPointUI.zip проверен в Mesa/OpenGL:
отдельный чёрный фон скрыт, кнопка видна и нажатие отключает UI.
Исходный интерфейс в проверке не переписывался.
Копирование, проверка файлов, резервирование и откат установщика проверены
на временных папках. Запуск этого CMD и диалога установки на Windows здесь
не проверялся; не утверждается, что обновление уже установлено на вашем ПК.
