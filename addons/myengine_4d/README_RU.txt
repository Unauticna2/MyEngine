MyEngine 4D Hierarchy 1.1.0 — импорт и экспорт, Blender 3.1

УСТАНОВКА
Edit -> Preferences -> Add-ons: удали старый MyEngine 4D Hierarchy.
Перезапусти Blender. Нажми Install, выбери MyEngine_Blender_4D_1_1_0.zip
и включи Import-Export: MyEngine 4D Hierarchy.
В панели N -> MyEngine и меню File -> Import / Export видна версия 1.1.0.
Аддон использует API Blender 3.x; mesh.corner_normals не требуется.

ИМПОРТ .4D В BLENDER
Object Mode -> File -> Import -> MyEngine 4D 1.1.0 (.4d).
Та же кнопка Import .4d есть справа в 3D View: N -> MyEngine.
Выбери файл .4d и нажми Import MyEngine 4D 1.1.0.
Появится новая коллекция с именем файла, корневой Empty и цепочка слоёв:
корень-контейнер -> W000 -> W001 -> W002 и далее.
Каждый слой — редактируемый Mesh; пустой слой — Empty.
Объекты, которые в файле находятся в одном слое, объединяются в один Mesh.
Исходные ветви родительской иерархии файл не хранит: создаётся цепочка,
сохраняющая порядок и глубину W, а не исходная организация объектов.

Все слои сохраняют исходные XYZ-координаты, поэтому видны друг поверх друга.
W — дополнительное измерение, оно не превращается в смещение по X/Y/Z.
Для редактирования отдельного слоя выделяй его в Outliner. Перед экспортом
снова выдели корневой Empty. Если скрывал слои, верни их видимость или
включи Include hidden geometry, чтобы экспортировать все слои.

Импорт читает UV, нормали и группы сглаживания OBJ. Материалы/изображения
из внешних MTL не импортируются; файл экспортёра их не содержит.
Модификаторы и анимация не восстанавливаются: .4d содержит готовую геометрию.
Шаг W берётся из заголовка .4d, для старых файлов используется 0.1.
Он сохраняется на корне и редактируется в N -> MyEngine при выбранном корне.
Разные импортированные модели могут иметь разный шаг W.
Оси движка X,Y,Z преобразуются обратно в Blender X,-Z,Y.
Старый формат с завершающим '+' поддерживается.
Существующая сцена не очищается. При ошибке создания удаляются только
объекты/меши/коллекция незавершённого импорта. Импорт поддерживает Undo.

ЭКСПОРТ И ПОВТОРНЫЙ ЭКСПОРТ
Выдели корневой объект. File -> Export -> MyEngine 4D 1.1.0 (.4d).
Панель N -> MyEngine: шаг W, экспорт и Duplicate as child layer.
У импортированного корня автоматически выбирается Children are layer 0
и его собственный шаг W. В окне экспорта эти параметры можно изменить.
После Duplicate as child layer выделен новый ребёнок; снова выдели корень.

Каждый уровень вложенности — следующий W-слой. Шаг по умолчанию 0.1.
Корень Mesh: 0; его дети: 0.1; внуки: 0.2. Соседи объединяются в один слой.
Корень Empty в режиме Auto — только контейнер, дети начинаются с W=0.
Root is layer 0 включает сам корень; Children are layer 0 исключает его.
Внутренние Empty создают промежуток по W. Геометрия родителя не повторяется
в слоях потомков. Все потомки включаются независимо от выделения.

Экспорт сохраняет UV, нормали, трансформации и результат модификаторов.
Нормали читаются из loop.normal после calc_normals_split в Blender 3.1;
при отсутствии API используются нормали граней/вершин с учётом сглаживания.
Материалы и изображения назначай в движке. Оси X,Y,Z -> X,Z,-Y.
Pivot корня становится началом координат; его поворот/масштаб запекаются.
Скрытые объекты исключены по умолчанию (есть Include hidden geometry).
Коллекционные/Geometry Nodes instances сначала преобразуй в реальную
геометрию. Экспортируется текущее состояние, а не анимация во времени.
До 256 слоёв, 64 MiB на файл. Экспорт при ошибке не перезаписывает старый файл.

Сохрани .4d в assets проекта MyEngine R26+, открой двойным щелчком в Project:
шаг W автоматически прочитается из заголовка. Старым движкам до R26 пустые
слои и метаданные шага неизвестны — сначала установи обновление движка.
Для обновления одного аддона пересобирать MyEngine не нужно.

ПРОВЕРКА
44 автоматических теста: чтение реального assets/spherecube.4d, обратное
преобразование осей, UV-швы и нормали, пустые слои, глубина и шаг W,
повторный экспорт с чтением движком, очистка при ошибке, подключение меню
на тестовом bpy, прежние проверки экспортёра и R26.
Blender в среде сборки отсутствует: установка/интерфейс и реальный bpy
здесь не запускались. Проверки геометрии используют тестовые объекты.
